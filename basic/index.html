TRAINING TOOL

PC操作シミュレーター with AI 基本編

AIをもっと便利に使うために欠かせない、6つの基本操作を練習します。

説明を読んだら、その場で実際にキーを押してみましょう。正しく操作できると「成功」と表示されて、次に進めます。読むだけの教材ではありません。手を動かしながら、自然に覚えていきましょう。

  • ① 全選択
  • ② コピー
  • ③ 貼り付け
  • ④ スクリーンショット
  • ⑤ 元に戻す
  • ⑥ やり直す

Windows・Macのどちらでも練習できます。

STEP 1 / 6

全部選ぶ：全選択

文章やファイルなど、表示されているものをまとめて選びたいときに使う操作です。

Windows
Ctrl+A
Mac
Cmd+A
練習エリア

下の文章をクリックしてから、全選択のショートカットを押してください。

うまくいかないとき

文章をクリックしてから、指を離さずに Ctrl（Macは⌘）を押しながら A を押します。文章全体の背景色が変われば成功です。

STEP 2 / 6

コピーする

選んだ内容を、パソコンに一時的に覚えさせる操作です。あとで別の場所に貼り付けられます。

Windows
Ctrl+C
Mac
Cmd+C
練習エリア

① まず、下の文章をクリックして全選択しましょう（Windows: Ctrl+A／Mac: Command+A）。

② 選べたら、コピーしましょう（Windows: Ctrl+C／Mac: Command+C）。

うまくいかないとき

選択して文字の背景が変わった状態のまま、Ctrl（⌘）+ C を押します。何も表示は変わりませんが、パソコンの中にコピーされています。

STEP 3 / 6

貼り付ける

コピーした内容を、別の場所に貼り付ける操作です。AIに質問するときも、この流れをよく使います。

Windows
Ctrl+V
Mac
Cmd+V
練習エリア

さっきコピーした文章を、下の「AIへの質問欄」に貼り付けてください。

うまくいかないとき

入力欄をクリックしてカーソルを点滅させてから、Ctrl（⌘）+ V を押します。Step2でコピーができていないときは、Step2からやり直しましょう。

STEP 4 / 6

画面を撮る：スクリーンショット

画面の一部を、写真のように切り取って保存する操作です。困った画面が出たとき、そのままAIに見せて質問できます。

Windows
Win+Shift+S
Mac
Cmd+Shift+4
練習エリア

① まず、下の白い四角をスクショしてください。

この白い四角を
スクショで切り取って

（※きっちりじゃなくて大体でいいです）

② 撮れたら、下の「AIチャットへの入力欄」をクリックして貼り付けてください（Ctrl+V）。範囲を選んだ時点で自動的にコピーされています。

② 撮れたら、画面の隅に一瞬出てくる小さな画像（サムネイル）を、消える前に下の「AIチャットへの入力欄」までドラッグしてください。

うまくいかないとき

Windowsは範囲を四角く選ぶと、自動でコピーされます。そのまま入力欄をクリックして貼り付けて（Ctrl+V）ください。Macの初期設定は、貼り付け用にコピーされるのではなく、デスクトップに画像として保存される仕組みになっているため、Cmd+Vでは貼り付けられません。画面の隅に出てくる小さな画像を、消える前に入力欄へドラッグしてください。

STEP 5 / 6

元に戻す：Undo

操作を間違えたときに、ひとつ前の状態に戻せる操作です。消しすぎても安心です。

Windows
Ctrl+Z
Mac
Cmd+Z
練習エリア

① 文章の一部をドラッグして選び、Deleteキー（またはBackspace）で消してください。

② 消えたら、元に戻すショートカットを押してください（Windows: Ctrl+Z／Mac: Command+Z）。

うまくいかないとき

文字を消したあと、すぐに Ctrl（⌘）+ Z を押します。消した文字が戻ってきたら成功です。

STEP 6 / 6

やり直す：Redo

元に戻した操作を、もう一度やり直せる操作です。「戻しすぎた」ときに使います。

Windows
Ctrl+Shift+Z または Ctrl+Y
Mac
Cmd+Shift+Z
練習エリア

さっき元に戻した文章から、もう一度「やり直し」をしてみましょう。

うまくいかないとき

Windowsは Ctrl+Y でもOKです。Macは Cmd+Shift+Z です。押したあと、さっき消えた部分がもう一度消えれば成功です。

CLEAR

お疲れさまでした

6つの基本操作を、実際に手を動かして練習しました。

  • 1全選択Ctrl / Cmd + A
  • 2コピーCtrl / Cmd + C
  • 3貼り付けCtrl / Cmd + V
  • 4スクリーンショットWin+Shift+S / Cmd+Shift+4
  • 5元に戻すCtrl / Cmd + Z

とくに「スクリーンショット→貼り付け」の流れは、AIに画面を見せて質問するときの基本になります。ぜひ普段の作業でも使ってみてください。
