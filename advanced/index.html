TRAINING TOOL

PC操作シミュレーター with AI 応用編

第一弾の続きです。ファイルの整理や、見やすくする操作など、7つの基本操作を練習します。

今回もやり方は同じです。説明を読んだら、その場で実際にキーやマウスを操作してみましょう。正しくできると「成功！」と表示されて、次に進めます。

  • ① 拡大・縮小
  • ② フォルダ作成
  • ③ 保存
  • ④ ファイル名変更
  • ⑤ 複数選択
  • ⑥ 右クリック
  • ⑦ 全画面のスクショ

Windows・Macのどちらでも練習できます。

STEP 1 / 7

大きくする・小さくする：拡大・縮小

文字が小さくて読みにくいときに、文字をその場で大きくしたり、小さくしたりする操作です。

Windows
全選択Ctrl+A
拡大Ctrl++
縮小Ctrl+-
Mac
全選択Cmd+A
拡大Cmd++
縮小Cmd+-
練習エリア

① 下の文字をクリックして、点滅カーソルを出し、全選択してください（Windows: Ctrl+A／Mac: Command+A）。第一弾の復習です。

② 選んだまま、文字を拡大してください。1回だけ押せばOKです（Windows: Ctrl と +／Mac: Command と +）。

③ 大きくなったら、縮小して元の大きさに戻しましょう。これも1回だけ押せばOKです（Windows: Ctrl と -／Mac: Command と -）。

文字の大きさ：100%

うまくいかないとき

先に文字をクリックして、点滅するカーソルを出し、全選択してから拡大してください。この練習では、画面全体ではなく、下の文字だけが大きくなるように調整しています。画面全体の大きさが変わったままになったときは、Ctrl（Command）+ 0 で元に戻せます。+ のキーは、Shift を押しながら「;」や「=」のキーを押す場合があります。

STEP 2 / 7

フォルダをつくる：フォルダ作成

バラバラのファイルを、ひとつのフォルダにまとめて整理する操作です。あとで探しやすくなります。

マウス操作（Windows・Mac共通）
クリック→ドラッグ
練習エリア

① 「＋ 新しいフォルダ」を押して、名前を「AI寺子屋」にして Enter を押してください。

② できたフォルダに、3つのファイルをドラッグして入れましょう。

デスクトップ

    うまくいかないとき

    ファイルをマウスでつかんだまま（ボタンを押したまま）、フォルダの上まで動かしてから指を離します。フォルダが緑色になったら離すタイミングです。日本語で名前を入力するときは、変換を確定するための Enter と、名前を決める Enter を1回ずつ押します。

    STEP 3 / 7

    残しておく：保存

    書いたり直したりした内容を、ファイルとして残しておく操作です。保存しないと、閉じたときに消えてしまうことがあります。

    Windows
    Ctrl+S
    Mac
    Cmd+S
    練習エリア

    ① 下のメモの最後に、今日の学びを1行書き足してください。

    ② 保存しましょう（Windows: Ctrl+S／Mac: Command+S）。

    議事メモ.txt✓ 保存済み
    うまくいかないとき

    メモの中をクリックして文字を書き足すと、右上が「● 未保存」に変わります。そのあと Ctrl（Macは Command）を押しながら S を押すと保存されます。

    STEP 4 / 7

    名前をつけかえる：ファイル名変更

    ファイルの名前を、あとで見てもわかりやすい名前に付けかえる操作です。

    Windows
    F2
    Mac
    Enter
    練習エリア

    ① 「スクリーンショット…」のファイルを、クリックして選んでください。

    ② 「スクリーンショット...」のファイルを「ENTER」にしてください。

    ③ 「講義資料01」と入力して、Enter を押してください。

    デスクトップ

      うまくいかないとき

      「スクリーンショット…」の行が青くなっていれば選べています。その状態で、Windowsは F2、Macは Enter を押すと、名前の部分が書き換えられるようになります。（拡張子の「.png」は変えません。）

      STEP 5 / 7

      まとめて選ぶ：複数選択

      ファイルを何個か、いっぺんに選ぶ操作です。まとめてコピーしたり、移動したりできます。

      Windows
      連続でShift+クリック
      飛び飛びでCtrl+クリック
      Mac
      連続でShift+クリック
      練習エリア

      ① 1つ目をクリックしてから、Shift を押しながら3つ目以降（3・4・5つ目のどれか）をクリックしてください（1つ目からそこまでが、まとめて選ばれます）。

      ② 今度は、Ctrl を押しながら、1つ目・3つ目・5つ目を順番にクリックしてください（1・3・5つ目だけが選ばれます）。

      講義フォルダ

        うまくいかないとき

        Shift は「ここからここまで」と覚えると簡単です（Windowsは、Ctrl が「これとこれとこれ」です）。キーを押したままクリックして、クリックしたあとにキーを離します。選んだ数は、下に表示されます。

        STEP 6 / 7

        メニューを出す：右クリック

        ファイルや文字の上でメニューを出して、やりたい操作を選ぶ方法です。ショートカットを知らなくても、これで大体のことができます。

        マウス操作（Windows・Mac共通）
        右クリック

        トラックパッドは、2本指でクリック（または Control を押しながらクリック）します。

        練習エリア

        ① 下の「メモ.txt」の上で、右クリックしてください。

        ② 出てきたメニューから、「コピー」を選んでください。

        デスクトップ
        • txtメモ.txt
        うまくいかないとき

        「メモ.txt」の文字の上にマウスを合わせてから、右側のボタンを押します。メニューが出たら、そのまま「コピー」をクリックします。メニューを消したいときは、何もない場所をクリックします。

        STEP 7 / 7

        画面ぜんぶを撮る：全画面スクショ

        いま見えている画面全体を、そのまま写真にする操作です。画面ぜんぶをAIに見せて質問したいときに便利です。

        Windows
        PrtScn

        ノートパソコンは Fn を押しながら PrtScn の場合があります。

        Mac
        Cmd+Shift+3
        練習エリア

        ① いま見えているこの画面を、まるごと撮影してください。枠はありません。画面ぜんぶが撮影の対象です。

        ② 撮れたら、下の「AIチャットへの入力欄」をクリックして貼り付けてください（Ctrl+V）。自動的にコピーされています。

        ② 撮れたら、画面の隅に一瞬出てくる小さな画像（サムネイル）を、消える前に下の「AIチャットへの入力欄」までドラッグしてください。

        うまくいかないとき

        Windowsは Win + Shift + S を押して、上に出てくるメニューから「全画面」を選んでも撮れます。Macの初期設定は、貼り付け用にコピーされるのではなく、デスクトップに画像として保存されるため、Cmd+Vでは貼り付けられません。画面の隅に出てくる小さな画像を、消える前に入力欄へドラッグしてください。画面の一部だけを撮った場合は、もう一度撮り直しになります。
